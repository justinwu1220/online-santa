# closing：捐贈收據與結案文件

活動結案要做兩件事：開收據給捐贈人、產生報送主管機關的文件。這個套件負責這些，資料來源是**已開立的收據快照**
（`donation_receipts`，開立後不可修改，要改就作廢重開）。

## 觀念

- **檔期（Campaign）**：一個活動期間（勸募期間、財物使用期間、願望上架期間、收據前綴、許可文號）。
  統計與收據歸屬都以「實際收到日落在 `[本檔期開始, 下一檔期開始)`」為準。
- **收據**：認領完成且機構驗收後自動開立，編號 `OS2026-000001`。三聯單：**紅聯給捐贈人（寄信）；
  白聯、黃聯由協會留存（只在管理員匯出提供）**。PDF 由 `pdf/ReceiptPdfRenderer` 以範本 PDF 為底、
  向量繪字產生（`GlyphOutlines`，不依賴系統字型）。
- **結案文件包**：`ClosingExportService.startPackage` 建立匯出、前端反覆呼叫 `advance`（每次約 15 秒預算），
  由 `doc/ClosingPackageBuilder` 組出壓縮檔。**成果備查與結案備查不再分開產出**：結案即視為兩者都完成，
  一次產生一包，資料截止日固定是檔期的財物使用結束日。官網仍是兩張表，所以附件照各自的編號：
  C 是 `02_捐物人資料`，D 是 `03_執行(服務)成果報告` 與 `04_支出明細資料`，都放在 `02_交給康乃心/` 底下。

## 規則（改之前先看）

1. **不編造**：系統不知道的（個人實際領受、議決、簽章）寫「待補」或「【待確認】」。
   **本活動沒有現金捐款**（需求方已確認），所以現金、利息、自籌、現金實支在所有文件固定為 0，
   沒有財務資料可輸入；所得與支出就是物資時價，賸餘 0。
2. 簽章、用印一律留白。
3. 公開輸出只放公開名稱、日期、物資、數量、時價、機構名稱（見 `docs/PRIVACY.md`「結案文件與公開徵信」）。
4. 收據不可改；錯了就作廢重開，新編號。
5. 結案暫存檔 30 天由排程清除（`ClosingCleanupService`）。
6. 壓縮檔裡只放**一個** HTML：根目錄的 `照表操作.html`。要加畫面就加頁籤，不要再開新檔案。
7. **勸募團體全銜一律用 `app.closing.organizer`**（設定檔），不跟著檔期的合作機構變；
   檔期的「合作機構」只決定 05C 與「本會直接發放份數」。換合作機構時連同下面那張表一起改。
8. **待確認的欄位照樣可以複製**：複製鈕只有在欄位完全沒有內容時才停用；還有「【待確認】」時是提醒色，
   按下去會複製並跳出提醒，避免把待確認的字貼上官網後忘記補。
9. **照表操作頁的財物使用情形固定兩列**（不按受贈機構拆）：「聖誕禮物」＝全部物資時價，
   明細「外部機構領受及康乃心個人領受；同一物資僅計一次」；「活動必要支出」明細「本會自籌郵資及結案列印費」，金額全 0。
10. 需求方已決定的固定值（2026-11-24）：財物所得用途第 2～10 類一律 0；預募金額用 `app.closing.planned-amount`
   （預設 500,000）；05A／B／C 頁尾標產生日期；05B／05C 不再有個資告知那一行。活動編號是檔期設定的必填欄位，
   照表操作頁兩處都讀它。

## 換合作機構時要改的地方

勸募團體全銜與下面這些「康乃心」短名都是寫死的（素材本來就是為康乃心做的）：

| 位置 | 內容 |
|---|---|
| `app.closing.organizer` | 勸募團體全銜「社團法人彰化縣康乃心關懷協會」（成果報告、核章 PDF 表頭、05A 轉贈單位、05B／05C 主辦、Facebook） |
| `doc/ClosingDocs.FOLDER` | 壓縮檔資料夾 `02_交給康乃心/` |
| `doc/FacebookPackageBuilder` | `02_交給康乃心/Facebook公開徵信/` |
| `doc/OrgFormPdfWriter` | 05C 的路徑與檔名（`04_機構確認/康乃心自身服務對象/05C_康乃心服務對象物資領受確認表.pdf`）、標題、05A 的「本機構確認受領康乃心轉贈…」「康乃心核對人簽章」、05C 的「康乃心全部受贈人合併一檔…」 |
| `resources/closing/templates/operation.html` | 頁首「康乃心結案填報資料」、「康乃心填寫」「康乃心自行準備及上傳」等提示 |
| `doc/OperationPageFiller.itemLines` | 財物使用情形第 1 列的明細「外部機構領受及**康乃心**個人領受…」 |

照表操作頁是衛福部官網的對照素材、05A／05B／05C 是 Word 範本重繪，換主辦單位時這兩份素材本來就要重做，
所以沒有把短名參數化。真的要換，先改上表四處，再重新產生一份文件包逐頁核對。
